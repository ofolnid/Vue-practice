# Vue 실습과제

## 1. Weather Mockup

### 1.1 기본 구현

- v-for를 통한 배열 렌더링으로 날씨 데이터를 반복 출력했다.
- v-if 조건부 렌더링으로 기온이 25도 이상이면 더움, 25도 미만이면 선선함 라벨이 렌더링되게 했다.
- 양방향 바인딩(단방향 바인딩 + 이벤트를 통한 갱신으로 양방향 구현, :value, @input)을 검색용 인풋에 구현해 검색 쿼리를 추적하고 화면에 표시하게 했다.
- 날씨 카드 선택 이벤트, 상세보기 클릭 이벤트를 구현했다.

### 1.2 추가 구현

- 기본 제공된 날씨 목업 데이터에 습도와 강수 확률 항목을 추가했다.
- 이를 토대로 불쾌 지수를 계산하여, v-if를 활용해 불쾌지수 정도에 따라 매우 불쾌/불쾌/보통 라벨이 렌더링 될 수 있도록 했다.

### 1.3 트러블슈팅 & 배운 점

- 상세보기 클릭 이벤트(Alert 창)가 실행되지 않는 문제
  - 파라미터에서는 city, 내부 실행문에서는 cityName으로 작성해 변수명 불일치로 함수가 실행되지 않고 있었다.
  - 수정 후 정상 작동 확인

## 3. Weather Component

### 3.1 기본 구현

- 기능 변경 없이 기존 Weather Composition의 구현 내용을 4개의 Component 파일로 분리했다.
- slot을 활용해 검색박스, 리스트박스의 디자인을 공통화했다.
- props와 emit을 활용해 WeatherParent와 WeatherCard, SearchBar 사이의 데이터와 이벤트 전달을 구현했다.
- 각 컴포넌트에 한정된 디자인을 scoped style로 분리했다.

### 3.2 추가 구현

- EmptyState 컴포넌트를 추가 분리하여 결과가 없을 때 렌더링할 공통 컴포넌트를 생성했다.

### 3.3 트러블슈팅 & 배운 점

- 부모-자식 사이 이벤트가 제대로 발생하지 않는 문제
  - emit을 통해 부모에게 전달할 때, emit 이름을 '' 따옴표 안에 작성하지 않아 존재하지 않는 함수라는 에러가 발생했다.
  - 수정 후 정상 작동 확인
- slot을 컴포넌트처럼 구성
  - 처음엔 slot의 역할을 공통 컴포넌트일 것이라고 잘못 이해하고 있어 내부에 title, content를 분리해 받으려고 했다.
  - 템플릿 또는 레이아웃 역할을 수행하는 것에 가깝다는 것을 이해하고(예를 들자면 모달 레이어 내부같은 역할) 수정했다.

## 4. Weather Router

### 4.1 기본 구현

- Vue Router를 설정하고 라우터 지연 로딩과 Catch-all Route(Not Found)를 적용했다.
- NavBar 컴포넌트를 분리 생성하고, RouterView와 함께 App 내에 배치했다.
- 홈, 어바웃 페이지를 생성하고 홈을 제외한 페이지에 메인 대시보드로 돌아가는 버튼을 추가했다.
- 디테일 페이지를 생성하고 동적 경로에 매칭되는 cityId의 데이터를 출력하도록 했다.
- 잘못된 경로로 진입할 경우를 캐치해 렌더링될 Not Found 페이지를 생성했다.

### 4.2 추가 구현

- 목업 데이터의 통계를 볼 수 있는 WeatherStatistics 페이지를 생성 및 구현했다.
- 페이지를 만들며 반복되는 코드를 컴포넌트화하여 분리했다. (InfoRow, AboutCard, StatCard)

### 4.3 트러블 슈팅 & 배운 점

- 공통 스타일 문제
  - 공통적으로 적용되어야 할 스타일(box-sizing: border-box 등)이 제대로 적용되지 않았다.
  - 상위 컴포넌트에서 적용한다고 하더라도 scoped라면 하위 컴포넌트에는 적용되지 않음을 확인했다.
  - App에서 scoped가 아닌 전역 스타일로 공통 스타일을 정의해 해결했다.
